            OpenAgile a Personal + AI-Agent Kanban Board Help

            Quick Start

            • Open controls: Click the ellipsis (⋮) button in the header.
            • Local-first: Everything runs in your browser; data is stored in localStorage.

            Links

            • GitHub Repository
            • ⭐ Star this project on GitHub
            • Documentation (GitHub)

            Groups & Iterations

            • Groups hold iterations; each iteration is a full board.
            • New group: Click the plus next to Groups, then type a name.
            • New iteration: Click the plus on a group header.
            • Rename: Double-click a group or iteration name.
            • Delete: Hover a group or iteration and click the ×.

            Tasks

            • Add: Use the Add task control in the HIL column header to add a task by hand; Backlog and the other columns are driven by agents.
            • Edit: Click a task row to edit details (title, description, key points and notes).
            • Move: Drag and drop between columns.

            Columns

            • The board has five fixed columns: Backlog, HIL, In Progress, Blocked, Finished.
            • Each column scrolls independently, so long task lists stay manageable.

            Labels & Label Groups

            • Manage: Use Manage Labels to create, edit, delete.
            • Groups: Optionally assign labels to a group (e.g., People, Status, Activity) to keep things organized.
            • Search: Label search matches both label names and group names.

            Settings

            • Open Settings from the controls menu to customize board preferences (locale, updated date/time, swim lanes).
